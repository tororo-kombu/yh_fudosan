## 物件情報の作成方法
1. [投稿管理画面 (https://y-fudosan.com/wp-admin/edit.php)](https://y-fudosan.com/wp-admin/edit.php)にアクセス
2. 必要であればログイン(``ID:メールアドレス pass: ``)
3. ｢新規投稿を作成｣をクリック
4. 記事の編集画面が開かれたら...  
   - 右メニューから｢アイキャッチ画像を設定｣を押して画像をアップロードし選択すれば物件情報のサムネイルになる。  
   - 真ん中の編集画面でタイトルや本文を編集。
   - 左上の｢+｣ボタンから画像ブロックを追加すれば本文内に画像を追加可能。

## 技術仕様メモ
- このwebサイトはwordpressを使用しており、当リポジトリはwordpressの独自テーマフォルダです。
- 構築環境ではLocalを使用していました。(y-fudosan-2)
- サーバーはXserver
- **このサイトでは物件情報のみWordPressのデータベースから動的に取得しています。**  
WordPressの記事一覧コンポーネントを設置した固定ページを作成し、そこから``script-list-ajex.js``で必要な要素だけindexページに非同期で挿入しています。本番環境では``script-list-ajex.js``内の3行目をその固定ページのアドレスに変更してください。
- 構築環境admin ``ID:{name} , pass:000``
